# 区块链 JSON-RPC 网关（Python Bootstrap）

本地多上游 JSON-RPC 网关：按健康度/延迟选节点、传输故障自动切换重试、
最终性缓存随链重组失效、并发相同只读请求合并、方法策略与批量约束，
以及在预算内**等待交易达到指定确认深度或最终确定**（同一交易的等待轮询合并、
重组感知、超时/被重组结论明确可区分）。所有故障与重组均由本地确定性
假节点注入，结果可解释、可复现。

## 快速开始

```bash
uv run pytest -q                      # 46 个测试（真实 TCP 假节点）
uv run fastapi run main.py            # 启动 3 假节点 + 网关 (8000)
```
